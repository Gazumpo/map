# Climbing source review

Reviewed 12 October 2026.

## Source and scope

The source is the [Perth region index on theCrag](https://www.thecrag.com/en/climbing/australia/western-australia/perth).
The index contained 44 immediate child entries when reviewed. The map includes
all 41 outdoor entries that theCrag marked as located. Ringworld Boulders,
Rapidly new craggin, and the Climbing Gyms grouping had no location at this
level and are not plotted.

The layer deliberately uses the Perth index entries rather than every nested
sector, individual boulder, or route. This gives one useful point per named
destination without stacking many markers at effectively the same place.

## Fields and classification

Each feature retains the theCrag node ID, name, route count, guide URL, and
primary climbing type. The primary type is the first and largest route-style
category reported by theCrag. A location is shown in the bouldering layer when
that primary type is Bouldering. Every other primary type is shown in the
climbing layer, while the more specific type remains visible in its popup.

Coordinates are the centres of the area bounds published by theCrag. For a
large park or region, the dot is therefore an overview location and not a
parking point, trailhead, or guarantee of access to a particular route. Users
should follow the linked theCrag guide for current access and approach details.

Route counts and classifications are a dated snapshot of a collaboratively
edited guide and will change as theCrag is updated.
